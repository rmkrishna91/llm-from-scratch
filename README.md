# LLM from Scratch – Following Sebastian Raschka's Tutorial Series

This repository contains my implementation and notes as I follow along with Sebastian Raschka's excellent [LLM from Scratch](https://youtube.com/playlist?list=PLTKMiZHVd_2Licpov-ZK24j6oUnbhiPkm&si=sUeOHhXZv3S3cuqm) tutorial series.

The goal is to build a deep understanding of how large language models work — from tokenizing raw text to implementing the full transformer architecture and fine-tuning it for downstream tasks.
